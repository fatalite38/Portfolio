# Ícones SVG

Os SVGs são distribuídos localmente, sem dependência de bibliotecas ou CDN em execução.

## Tecnologias — Simple Icons

React, TypeScript, Node.js, Python e Supabase vêm de [Simple Icons](https://github.com/simple-icons/simple-icons/tree/e451c581fccb01b56f47e1a77292bdd1fd95b1a4), revisão `e451c581fccb01b56f47e1a77292bdd1fd95b1a4`, sob [CC0-1.0](LICENSE-SIMPLE-ICONS.md).

Os arquivos preservam os SVGs da coleção. `technologies/nodejs.svg` corresponde a `icons/nodedotjs.svg` na origem. A cor é aplicada por máscara CSS; os desenhos não foram modificados. Os metadados dessa revisão não indicam licenças individuais diferentes para os cinco ícones selecionados.
